# leonadvert

> **Leon Advert** — Premier Software Engineering & Digital Growth Agency website.

Built with [Next.js](https://nextjs.org), [Tailwind CSS](https://tailwindcss.com), [Framer Motion](https://www.framer.com/motion/), and [Lucide Icons](https://lucide.dev).

## ✨ Features
- **Hero & Value Proposition**: High-converting hero with animated badge, dynamic CTA, and live trust metrics.
- **Services Showcase**: Custom Web Development, Mobile Apps, Cloud Architecture, SEO & Performance Marketing.
- **Why Choose Us (Bento Grid)**: 5-card interactive grid highlighting speed, code quality, and security.
- **Execution Process**: 4-phase framework with deliverables and milestones.
- **Social Proof**: Testimonials and client results marquee.
- **Contact**: Interactive lead capture and direct consultation pathways.
- **Design System**: Tailored dark mode, glassmorphism, fluid responsive layouts for all device sizes.
- **Favicon & PWA**: Custom SVG/ICO crest favicons, Apple touch icons, and web manifest.

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript
